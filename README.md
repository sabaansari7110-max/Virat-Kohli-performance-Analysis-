# Virat Kohli — Performance Analysis

An interactive data analytics project exploring Virat Kohli's career batting statistics across formats (Test, ODI, T20I) and oppositions, built with Excel Pivot Tables and Power BI/Tableau dashboards to demonstrate data cleaning, analysis, and visualization skills.

##  Overview
This project analyzes Virat Kohli's batting performance across 516 international matches, covering 23,709 total runs across Test, ODI, and T20I formats against 18 different oppositions.

##  Objectives
- Compare run contribution and consistency across formats (Test, ODI, T20I)
- Analyze performance against different oppositions
- Identify strongest and weakest grounds/venues
- Visualize career trends through an interactive dashboard
